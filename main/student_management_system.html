About the Project

The Student Management System is a beginner-friendly Python application that helps users manage student information. It demonstrates programming fundamentals, data organization, and object-oriented programming.

Project Features

  • Add student records
  • View student information
  • Store student ID, name, course, and year level
  • Check for duplicate student IDs
  • Display a loading animation in the terminal

Technologies Used

Python OOP CLI Data Management
