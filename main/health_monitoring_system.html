About the Project

This project concept focuses on collecting heart rate and blood oxygen saturation readings and presenting them through a monitoring dashboard. It also proposes emergency alerts to notify a caregiver when needed.

Project Features

  • Heart rate monitoring
  • Blood oxygen saturation monitoring
  • Display readings on a dashboard
  • Real-time monitoring concept
  • Emergency alert and caregiver notification concept

Technologies Used

PROJECT OVERVIEW

Project Goals

The goal is to explore how sensors, embedded systems, and web technologies can be combined to display health readings and help caregivers respond to potential emergencies. This is a project concept and is not a substitute for professional medical equipment.
