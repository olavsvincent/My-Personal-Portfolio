About the Project

The Book Management System is a project concept for organizing book information and monitoring book availability. Its implementation can be adapted for a personal library or a small lending collection.

Project Features

  • Add and view book records
  • Store book titles, authors, and IDs
  • Track available and borrowed books
  • Record borrowed and returned books
  • Search for books in the collection
