About the Project

This is my personal portfolio website as a first-year Computer Engineering student. It showcases my background, skills, projects, and interests in technology and programming. It also includes interactive features that allow visitors to explore the website and try simple coding and learning activities.

Features

Navigation Bar – Links to Home, About, Skills, Projects, Contact, and IDE pages.
Light and Dark Mode – Allows visitors to switch between light and dark themes.
Hero Section – Introduces me as a Computer Engineering student and future computer engineer.
Interactive Terminal – Lets visitors type commands to explore information about me, my skills, and my projects.
Memory Challenge – A matching game where players find pairs and track their moves and time.
Programming Quiz – Tests basic knowledge of programming and web development.
Portfolio Chatbot – Provides predefined answers about my background, skills, projects, and programming topics.
Quick Navigation Search – Allows visitors to search for website pages and sections using a search interface.
Responsive Navigation – Includes a mobile menu for smaller screens.
Footer – Displays my name and the current year automatically.

Technologies Used

- HTML5 for website structure
- CSS3 for styling, layouts, and responsive design
- JavaScript for interactive features and functionality

How to Run

1. Download or clone the project files.
2. Keep the HTML, CSS, JavaScript, and image files in their correct folders.
3. Open `index.html` in a web browser.
4. Use the navigation bar to explore the different pages.
5. Try the interactive terminal, memory game, programming quiz, chatbot, and quick search.

For the Online Code Editor, open `editor.html`. An internet connection is needed to load the CodeMirror libraries from the CDN.
