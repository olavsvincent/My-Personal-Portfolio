VINCENT.DEV PROJECT LAB
=======================

Open project.html in a browser (preferably through VS Code Live Server).
The Projects gallery links have been updated to open the matching module in Project Lab.

Included working web apps:
- Calculator/
- Grade Calculator/
- Book Management System/
- Health Monitoring System/
- Workout Planner/

Student Management System is Python/CLI in the original project, so project.html includes a browser-based companion demo with localStorage and CSV export.
SysVision is a Flask app and needs its Python server; the Project Lab explains this instead of pretending browser-only diagnostics are real.

Notes:
- Keep project.html, project-demo.css, project-demo.js and the app folders together.
- Run with VS Code Live Server for best results.
- Local storage is browser/device-specific and is not synced between visitors.
